# 28-稍后再看

> 适用：维护「稍后再看」（本地收藏夹、跨站条目、帖子阅读进度、批量管理）时。非必读。

## 为什么要有第三条记录线

| | 浏览记录 | 稍后再看 | 收藏 |
|---|---|---|---|
| 存储 | 本地 sembast，上限 200 | 本地 sembast，**无自动淘汰** | 服务端 `favorite.php` |
| 登录 | 不需要 | 不需要 | 需要 |
| 对象 | 帖子 / 用户 / 我的帖子 / 回复 | 帖子 / 用户空间 / 版块 / 圈子 | 仅帖子 |
| 消失条件 | 被新记录挤走或手动清 | **只有手动删** | 服务端取消收藏 |

历史会被新记录挤走，收藏又依赖登录且只支持帖子，所以「临时记一下、回头再看」需要独立的一条线。**不要**把它实现成浏览记录的 flag：两者生命周期、清理语义、容量假设都不同。

## 数据与 key

模型 `lib/models/read_later_item.dart`，key 规则 `host:type:targetId`：

| type | key 示例 | routePath | 进度 |
|---|---|---|---|
| `thread` | `a.com:thread:123` | `/thread/123` | `page`（上次看到第几页） |
| `user` | `a.com:user:456` | `/user/456` | — |
| `forum` | `a.com:forum:2` | `/forum?fid=2` | — |
| `group` | `a.com:group:88` | `/groups/category?...` 或 `/groups/content?...` | — |
| `page` | `a.com:page:/my-threads?type=reply` | 原样保存当前页（不含 `page` 参数） | `page`（加入/翻页时记录） |

key 带 host 是硬要求：MT / 52 的 tid/uid/fid 各自独立编号，不带 host 会跨站互相覆盖（同 `BrowseRecord`，见 `docs/04`）。

快照字段（`title/subtitle/url`）只用于列表展示与"在浏览器打开"，打开后以服务端数据为准。

## 行为约定（改代码时不要破坏）

1. **打开不移除**：打开条目只 `markRead` / 回写 `page`，条目永远留到用户手动删。
2. **重复加入幂等**：保留原 `addedAt`（列表顺序不跳）与已读状态，只刷新快照和阅读进度。
3. **不写浏览记录**：两条线互不影响；清历史、历史超限淘汰都动不到稍后再看（反之亦然）。
4. **本地优先**：加入不需要登录，跨站临时会话（`SiteScope`）也能加入；所有写操作只落主库。
5. 帖子打开与翻页时由帖子页回写 `page` 并置已读（`_recordThreadHistory` + `_loadCommentPage`，见 `lib/pages/thread/thread_view_actions.dart`）；页面级条目（关注/好友/留言板/我的帖子）也记录 `page`，我的帖子在列表加载后同步更新；列表与详情显示「第 N 页」，打开时拼回 `page=N`。页码失效由目标页现有 clamp 兜底，这里不修正。

## 存储与状态

- 表：`read_later`（string key → Map），CRUD 在 `lib/core/utils/database_helper_records.dart`
- `ReadLaterProvider`（`lib/providers/read_later_provider.dart`）：全量跨站点、按 `addedAt` 倒序；`items/count/hosts` 支持站点 + 类型筛选；`SiteChangedEvent` 只触发通知，不清数据
- 启动时在 `lib/main.dart` 建实例并 `load()`，随 Provider 注入
- 不纳入设置导出（`data_portability` 不导出缓存/本地数据），换机不迁移是刻意取舍

## 入口与页面

- 不单独建页、不加路由：稍后再看是**浏览记录页的第一个 Tab**（`lib/pages/history/history_page.dart`），默认选中第二个「全部」Tab
  - 与历史共用站点筛选；"不按类型再分类"，一个 Tab 内平铺
  - 点击条目先弹**信息弹窗**（标题/类型/站点/路由/加入时间/状态/阅读进度/链接），再由用户选「前往查看」或「删除」
  - 列表显示**已读/未读**（已读条目整体降饱和 + 未读圆点）、类型、站点、加入时间；帖子额外显示「第 N 页」（含第 1 页）
  - 右上角菜单在「稍后再看」Tab 额外提供「清除已读（N）」，只删已读条目，未读保留
- 加入入口都在详情页 / 用户中心页的 `PageActions` 菜单（不做列表长按，避免和列表手势冲突）：
  - 帖子页 `thread_view_page.dart`（存当前页码）
  - 用户空间 `user_profile_page.dart`
  - 版块与圈子讨论区 `community_page.dart`（`readOnly` 时 type=group）
  - 圈子分类 `group_category_page.dart`
  - 页面级 `type=page`（`widgets/common/read_later_page_action.dart`）：关注/粉丝 `follow_page.dart`、好友 `friend_page.dart`、留言板 `wall_page.dart`、积分记录 `credit_log_page.dart`、我的帖子/最近回复 `my_thread_page.dart`。key 用 `host:page:routePath`（去掉 `page` 参数），页码单独存；`/my-threads`、`/follow`、`/friends`、`/user/:uid/wall` 路由都支持 `page=` 恢复。

## 跨站打开

只有 `thread` / `user` 支持带 `site=` 打开（与历史页同一限制，见 `docs/27`）：版块/圈子/页面级条目所属页面未接入站点作用域，跨站条目点击时提示不支持。列表里 `page > 1` 的帖子会拼 `?page=N`。
